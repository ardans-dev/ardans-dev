### Featured Projects & Deployments

#### 1. Hermes Jarvis (Autonomous Multimodal AI)
> **Repository:** [ardans-dev/hermes-jarvis](https://github.com/ardans-dev/hermes-jarvis) • **Live Bot:** [@ardans_ai_bot](https://t.me/ardans_ai_bot)  
> Autonomous 24/7 personal assistant on Microsoft Azure VM (`Standard_B2ats_v2`, East Asia):
> - **Voice-to-Voice Pipeline**: Real-time STT audio transcription and natural speech synthesis using Azure Neural Voice (`id-ID-GadisNeural`).
> - **Computer Vision**: Instant diagnostic parsing of error screenshots, cloud topologies, and slide documents.
> - **Live Server Telemetry**: Non-blocking diagnostics (`/status`) reporting VM CPU, memory, swap, and uptime.
> - **PM2 Daemon Supervision**: Fully automated process recovery and persistent multi-turn SQLite memory.

#### 2. Unimate AI (Study Companion & Document Analysis Engine)
> **Repository:** [ardans-dev/unimate-ai](https://github.com/ardans-dev/unimate-ai)  
> Full-featured academic AI assistant platform (v0.8.0):
> - **Extended Context Intelligence**: Qwen 2.5 8K token context window with empathetic student persona.
> - **12-Format Document Parser Factory**: Native ingestion of PDF, DOCX, PPTX, XLSX, EPUB, and source code files.
> - **3D Spatial Study Engine**: Interactive 3D learning models and spatial concept visualizer.

#### 3. Bengkel Mobil Ardans (Automotive Workshop Portal & POS)
> **Repository:** [ardans-dev/Bengkel-Mobil](https://github.com/ardans-dev/Bengkel-Mobil)  
> Integrated automotive workshop management and customer service portal:
> - **Public Service Tracker**: Privacy-safe invoice tracking without exposing customer data.
> - **Dynamic Operating Engine**: Real-time operating hours, automatic Indonesian holiday recognition, and admin overrides.
> - **Transactional POS Cashier**: Multi-item billing, inventory deduction with ACID transactions, and printable invoices.

#### 4. StudyMind AI (Hybrid RAG Intelligence Platform)
> **Repository:** [ardans-dev/studymind-ai](https://github.com/ardans-dev/studymind-ai)  
> Local-first document question-answering and summarization platform:
> - **Hybrid Search Architecture**: Dense semantic retrieval (ChromaDB) combined with sparse lexical search (Rank-BM25).
> - **Cross-Encoder Reranking**: Advanced attention scoring for candidate passage precision.
> - **Source-Attributed Citations**: Transparent page and slide references with local Ollama inference.

#### 5. Web Kas Kelas (Class Cash Management System)
> **Repository:** [ardans-dev/web-kas-kelas](https://github.com/ardans-dev/web-kas-kelas)  
> Transparent financial management web application for student communities:
> - **Dues Tracking**: Automated weekly period schedules, dues payment status, and overdue calculations.
> - **Full-Stack Architecture**: React 19, TypeScript, Express 5, and SQLite database with CSV export.

#### 6. Asisten Mahasiswa (Cross-Platform Mobile Companion)
> **Repository:** [ardans-dev/asisten-mahasiswa](https://github.com/ardans-dev/asisten-mahasiswa)  
> Academic productivity application built with Flutter 3.x, Google Gemini AI, and Firebase Cloud Firestore.
